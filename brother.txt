# Brother iPrint&Scan Desktop — switched to Page (9/13, per the user) after real-hardware testing
# found the auto-download-and-run mechanism was getting caught by antivirus. The other three
# vendors' AV-adjacent problems (Canon, Epson) were solved by switching to a Microsoft Store app —
# checked whether Brother has an equivalent, and it doesn't for this: there's a "Brother Print
# Support App" on the Store, but it's print-only (no scan) and requires Windows 11 24H2+, so it's
# not a real substitute for iPrint&Scan's scan-to-PC capability.
#
# Instead of our own script silently downloading a fresh .exe and immediately launching it (exactly
# the "download-then-execute" pattern AV/EDR heuristics are tuned to flag), this now just opens the
# same URL — confirmed correct and working (8/27, manually tested by the user) — in the user's own
# browser, so download + run happens the normal, human-driven way a browser handles it.
